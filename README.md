# cyberskillbattle
# 🌐 CYBER_DECK: 10_STAGES_ENVIRONMENTS

> 全10ステージ、異なる環境を駆け抜ける本格サイバーパンク・カードバトルゲーム。Python (Streamlit) で構築されたWebアプリケーションです[cite: 15]。

---

## 🎯 概要 (Overview)
『CYBER_DECK』は、3人の精鋭エージェントを率い、スラム街から最終電脳空間まで全10ステージの過酷な環境を突破していくストラテジー・カードバトルゲームです[cite: 15]。
限られたRAM（コスト）を管理しながら、攻撃・防御・回復のカードを駆使して強力なボスたちに立ち向かいます[cite: 15]。

---

## 👥 エージェント & スキルシステム (Agents & Cards)
プレイヤーは以下の3人のエージェント部隊を指揮します[cite: 15]。各キャラクターは**10個の固有スキルカード（総計30種以上）**を保有しています[cite: 15]。

*   **詩音 (Shion):** サイバーニンジャ。素早い身のこなしと連続攻撃を得意とするアタッカー。
*   **サイファー (Cipher):** スナイパー。遠距離からの精密射撃で敵の弱点を撃ち抜く。
*   **アイリーン (Aileen):** 重装アーマー。堅固なシールドとヒールで味方を守るタンク・サポート役。

---

## ⚙️ 主なゲームシステム (Features)
*   **戦略的RAMシステム:** 毎ターン支給されるRAMコストの範囲内で、どのカードを切るか選択する高い戦術性[cite: 15]。
*   **敵の特殊AIと脅威:** ステージが進むにつれて、こちらのシールドを無視してHPを直接削る「防御貫通攻撃」などの厄介なスキルを敵が使用。
*   **ステージクリア報酬 (ローグライク要素):** 
    *   **リヴァイブ:** 戦闘不能になった仲間をリペアして復活。
    *   **ステータス強化:** MaxHPのアップやスキル効果量の強化を選択し、次のエリアへ備える。
*   **クリア後評価:** 全10ステージを走破すると、生存ターン数やクリア状況に応じたスコアとランク（最高ランク『S』）が算出されます[cite: 15]。

## 🚀 遊び方 / 実行方法 (Getting Started)

ローカル環境で実行する場合は、以下の手順に従ってください。

### 1. リポジトリのクローン
```bash
git clone [https://github.com/your-username/cyber-deck.git](https://github.com/your-username/cyber-deck.git)
cd cyber-deck
```
### 2. 依存ライブラリのインストール
```bash
pip install streamlit
```
### 3. アプリケーションの起動
```bash
streamlit run app.py
```
